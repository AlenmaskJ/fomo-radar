# 动态机会雷达使用说明

## 一键启动

双击项目根目录的 `start-demo.cmd`。脚本会启动 `fomo-server.exe`（网页、主流币雷达和美股雷达）以及 `fomo-scanner.exe -watch`（新币雷达），两个进程共用同一个 SQLite 数据库；首次主流币完整扫描通常需要 1～3 分钟，健康检查通过后会自动打开：

```text
http://127.0.0.1:18080/market
```

美股雷达入口：

```text
http://127.0.0.1:18080/stocks
```

启动脚本仍只等待主流币健康检查，不会因为首次美股扫描较慢而阻止打开页面，也不会启动独立的股票进程。

默认代理是 `http://127.0.0.1:10808`。需要修改时，请在 CMD 中运行：

```bat
set FOMO_PROXY=http://127.0.0.1:10808
start-demo.cmd
```

没有代理时可先执行 `set FOMO_PROXY=`。

## 扫描节奏

- 新币雷达启动后立即扫描，之后按约 2 分钟的起始节奏持续扫描；耗时超过 2 分钟时不重叠运行。
- 启动和手动点击“立即扫描”：重建动态池并刷新 `15m / 1H / 4H / 1Dutc`。
- 每 2 分钟：价格、成交额、OI 和资金费率。
- 每 5 分钟：`15m`；每 15 分钟：`1H`；每小时：`4H`；每 4 小时：`1Dutc`。
- 每 30 分钟：分别重建最多 60 个标的的动态主流币池和美股池。
- 手动扫描有 60 秒冷却；已有扫描运行时不会重复启动。

两个雷达共用评分代码，但候选池、K 线缓存、扫描状态和数据库结果相互隔离。主流币使用 BTC 作为相对强弱基准；美股使用 SPY 作为基准，SPY 不进入候选榜单。美股池只接受静态审阅白名单内的美国上市个股，再从 OKX 当前可用股票永续合约中按流动性筛选。

## 美股路由

- 页面：`/stocks`
- 历史榜单：`/stocks/history`
- 扫描状态：`GET /api/stocks/status`
- 手动扫描：`POST /api/stocks/scan`
- 健康检查：`GET /health/stocks`

## 页面状态

- `completed`：本轮完整成功，包括“零候选”的正常行情。
- `degraded`：个别币或周期读取失败，其余安全结果仍发布。
- `failed`：批量行情或存储失败，页面保留上一份完整报告。
- “扫描结果已过期”：最近完整结果超过 10 分钟。

没有达到门槛的币时，页面显示“当前没有高质量机会”，不会为了凑数量展示普通行情。

美股雷达读取的是 OKX 股票永续合约，因此全天运行；美国现货休市期间，永续合约的流动性和价格偏差可能扩大，页面会固定显示该风险提示。

## 安全边界

程序只读取 OKX 免费公共行情，不需要 API Key，不读取账户，不调用下单接口。分批入场、止损和目标价仅用于研究与面试演示，不构成投资建议。

## 排错

排错时可分别在两个终端运行，以查看主流币/美股雷达和新币雷达日志。

终端一：

```bat
fomo-server.exe -serve -market-watch -db fomo.db -proxy http://127.0.0.1:10808 -listen 127.0.0.1:18080
```

终端二：

```bat
set FOMO_DB=fomo.db
set HTTP_PROXY=http://127.0.0.1:10808
set HTTPS_PROXY=http://127.0.0.1:10808
fomo-scanner.exe -watch
```

若代理不可用，日志会显示 OKX 网络错误；修正代理后重启，或在网页冷却结束后点击“立即扫描”。
